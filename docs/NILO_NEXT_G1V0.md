## Requested tests and failure gates

The target-native runner must run `node --test tests/golden-minute.test.mjs`, `node --test tests/golden-minute-mutation.test.mjs`, full original sources/physical mutations/bridge/DoD, Chrome `python tests/browser-golden.py --out /tmp/nilo-browser-golden --expected-sha <HEAD> --physical-mutant`, and all LV01/LV02/Custode/LV03 and static `dist/` browser regressions.

The first Playwright run opens two **real HTTP** pages using the same Canvas surface and captures the 120×70 original framebuffer region. It records distinct pixel colors, actual readback mode, screenshot PNG digests and the expected difference. The source mutant removes the visual draw from a physically copied `web/main.mjs` and is served on a different HTTP origin; the native pixel difference must disappear. This is evidence of visual detail and source ownership, **not** evidence of beauty, legibility or fun.

**Stop** when an original test fails, a mutant survives, a screenshot cannot be tied to the HEAD, a new module is missing from the reproducible `dist/`, or an external acceptance is silently promoted. **Rollback:** revert this slice; `?visual=legacy` remains the immediate A/B comparison. **Next:** independently review art and then add G1-V1 animation/asset composition on the same physical baselines; only after author choice of DA01 and DA07. **CORA-ENGINE:** NOT_RUN until a real pinned runner executes and replays its receipt.
