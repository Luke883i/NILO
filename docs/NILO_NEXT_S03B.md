**Status:** implementation candidate, not author approved. **Source of truth:** \`contracts/nilo-semantic-v1.json\` and original DoD \`contracts/dod-v1.json\`. **Base:** main after merged PR #17. The original NILO content owners, tests and release gates remain authoritative.

## A0 observable contract

**Actors:** desktop keyboard player Nilo, two original Cortile automata (\`cortile-sentry-01/02\`), three original Frammenti (\`shard-01/02/03\`), product author and independent reviewer. **Behavior:** movement and attack \`J\` can disable one original automaton; stomp, health, invulnerability and pickup state still work with exactly the same baseline behavior. **State/data:** blueprint is immutable and fail-closed; each initial game/restart instantiates fresh independent enemy and pickup objects with stable IDs, preserving original runtime keys, stats, patrol bounds, pickup positions and legacy checkpoint codecs.

**UX:** original player-visible words, sprites, enemy defeat feedback and geometry stay unchanged. **Exclusions:** no new archetype is enabled outside LV-01, no LV-04–LV-06, no new rewards, damage model, violence decision, assets, audio, external calls or telemetry. **Effects:** source-only module changes and new test artifacts; \`main\` untouched until human merge. Existing S02 DA01–DA09 and Q07 do not gain an approval receipt.

## Scope and dependency / owner map

- \`web/action.mjs\`: original \`BASE_ENEMIES\` / \`BASE_SHARDS\` become an exposed immutable \`LV01_ENTITY_BLUEPRINT\`; \`validateActionBlueprint\` rejects forged/missing/duplicated IDs, invalid positions, patrols or future-level masquerading; \`spawnActionEntities\` creates independent mutable state. The shared \`initialAction\` consumes that factory.
- \`web/core.mjs\`: actual consumer is **unchanged**; it continues calling \`initialAction\` and \`advanceAction\`. No second engine.
- \`OR-09\` in the product→software bridge owns source \`web/action.mjs\` and the core consumer; the two new tests are registered under LV-01 and in the repo suite.
- \`G_ACTION_ENTITIES_S03B\` is an AND child of existing \`G_FULL_GAME\` (90 nodes / 17 ANDs after S03b). It does not replace \`G_CREATIVE_A0_S02\`, Q07 or S03a.

## Falsification and rollback

\`tests/entity-blueprint.test.mjs\` exercises actual source and state, not just a JSON schema. \`tests/entity-blueprint-mutation.test.mjs\` writes the unmodified source to a physical temporary file and then writes altered JavaScript to another physical file; both are actually imported. Distinct counterexamples confirm bad identity, patrol, pickup position, enemy alias, pickup alias, and unauthorized LV-04 entity instantiation. An ESM import error, syntax error or changed byte string alone is not counted as a successful kill.

**Runner:** GitHub Actions on exact PR head, invoking both Node tests, original action mutation suite, \`scripts/verify.mjs\`, the product bridge, real HTTP Chrome E2Es and the deployment byte digest replay. All failures are stop gates.

**Rollback:** revert one S03b commit. **Survivors / external:** independent novice usability and author creative approval remain unresolved; expanding enemy archetypes and new levels belongs to S07 and later slices. **CORA-ENGINE:** NOT_RUN unless executed by a real pinned runner, with separate receipt.
